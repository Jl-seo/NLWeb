# Teams 앱 패키지

Teams는 **웹 앱을 꽂는 껍데기**입니다. 제품은 [`../web/`](../web/README.md) 의 React 앱이고,
이 디렉토리는 그 앱을 Teams 탭으로 노출하는 매니페스트와 빌더입니다.

## 왜 챗만으로는 부족한가

영향 분석 결과는 본질적으로 표입니다. 수십~수백 행에 홉수·근거·테스트 여부가 붙습니다.

- **잘립니다** — M365 플러그인·봇 응답은 토큰 윈도우에서 큰 콘텐츠가 truncate 됩니다.
  서비스가 `SAP_IMPACT_MAX_IMPACTED` 로 자르는 것도 같은 이유입니다.
- **상태가 없습니다** — 회귀 테스트 목록은 "이건 했고 저건 남았다"가 남아야 합니다.
- **결정 근거로 안 남습니다** — 실제 소비자는 전송요청 승인자·QA·이행 담당자이고,
  이들에게 필요한 건 대화가 아니라 공유·추적 가능한 목록입니다.

그래서 요약은 Adaptive Card로, 전체 목록은 탭으로 나눕니다. 분석 API는 양쪽이 그대로
공유하므로 표현 계층만 다릅니다.

## 구성

| 기능 | 대상 | 내용 |
|---|---|---|
| 개인 탭 | 개발자·QA | React 앱 전체 — 대시보드, 영향 분석, 코드 리뷰, 오브젝트 탐색, 에이전트 패널 |
| 채널 탭 | 팀 | 채널에 고정. `/app/config` 에서 기본 코드베이스 선택 |
| 봇 *(선택)* | 채팅 | 요약 카드 — 위험도·판정근거·상위 5건·사각지대, "전체 목록 열기" 딥링크 |
| 메시지 확장·링크 언퍼링 *(선택)* | 채팅 | 오브젝트 검색 후 카드 삽입, 서비스 도메인 링크 붙여넣기 시 카드 자동 표시 |

## 빌드

```bash
python make_icons.py            # 아이콘 재생성 (선택, PNG는 커밋되어 있음)

python build_package.py \
    --host sap-impact.azurewebsites.net \
    --app-id $(python -c "import uuid;print(uuid.uuid4())") \
    --developer "회사명" \
    [--bot-id <Azure Bot 앱 ID>] \
    [--sso-client-id <Entra 앱 클라이언트 ID>]
```

`sap-impact-teams-app.zip` 이 생성됩니다. Teams → 앱 → 앱 관리 → **앱 업로드** 로 사이드로드하거나
조직 카탈로그에 제출합니다.

- `--bot-id` 없이 빌드하면 **탭 전용** 패키지입니다. 서비스만 배포돼 있으면 바로 동작합니다.
- `--bot-id` 를 주면 봇·메시지 확장이 포함됩니다. 봇 메시징 엔드포인트가 `POST /cards/impact` 를
  호출해 카드를 반환하도록 구현돼 있어야 합니다(별도 봇 앱 필요).
- `--sso-client-id` 를 주면 탭 SSO(`webApplicationInfo`)가 포함됩니다. Entra 앱 등록과
  `api://<host>/<client-id>` 애플리케이션 ID URI 설정이 선행돼야 합니다.

## 인증

탭은 브라우저이므로 **API 키를 가질 수 없습니다.** 서비스는 두 가지 자격 증명을 받습니다.

| 호출자 | 자격 증명 |
|---|---|
| Foundry OpenAPI 도구 | `x-api-key` (custom keys 연결) 또는 관리 ID |
| Teams 탭 | App Service 인증(Easy Auth)이 검증 후 주입하는 `X-MS-CLIENT-PRINCIPAL-ID` |

Easy Auth는 클라이언트가 보낸 `X-MS-CLIENT-PRINCIPAL-*` 헤더를 제거한 뒤 자신이 검증한 값으로
교체합니다. **이 게이트웨이 없이 서비스를 공개 노출하면 해당 헤더를 위조할 수 있으므로**,
탭을 쓰려면 Easy Auth(또는 동등한 게이트웨이)를 반드시 앞단에 두십시오.

## 확인된 동작 / 확인하지 못한 것

브라우저(Chromium)로 검증한 것: 대시보드·영향 분석·코드 리뷰 화면 렌더링, 홉별 영향 경로 그래프,
diff 라인별 위험 주석, 에이전트 패널(미설정 상태 안내 포함), 라이트·다크 테마, 패키지 빌드.

검증하지 못한 것: **실제 Teams 클라이언트 안에서의 동작**. 이 환경에는 M365 테넌트가 없어
사이드로드·SSO·딥링크 복귀·카드 렌더링은 테넌트에서 한 번 확인해야 합니다. Teams JS SDK는
CDN에서 로드되며, 로드 실패 시에도 페이지는 일반 브라우저 모드로 동작하도록 작성돼 있습니다.
